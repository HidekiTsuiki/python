## AI の利用について

演習では，AI に考え方を聞いたり，バグを指摘してもらったり，AI にプログラムを作ってもらってその意味を考えたりしながら学習を進めます。京大の学生は，大学のアカウントで Gemini を使えます。自分で使っている他の AI を使っても構いません。

ただし，課題によっては AI の使い方を制限することがあります（各回の説明を読んでください）。AI を使った時は，何のために使ったかを明示し，プログラムの内容については自分のことばで説明できるようにしてください。

## 準備

授業には，自分のノートパソコン（Windows または Mac）を持参してください。

### VS Code と Python

この授業では，VS Code を標準の環境として使います。

1. Python をインストールします（https://www.python.org/ ）。Windows では，インストールの最初の画面で「Add python.exe to PATH」にチェックを入れてください。
2. VS Code をインストールします（https://code.visualstudio.com/ ）。
3. VS Code の拡張機能（左の四角いアイコン）で，「Python」と「Jupyter」をインストールします。

ライブラリ（numpy, matplotlib など）は，ノートブックのコードセルで `%pip install numpy matplotlib` のように実行するとインストールできます。

### 教材のダウンロード

教材は，授業の前に更新されることがあります。git を使うと，更新を簡単に取り込めます。

1. git をインストールします（https://git-scm.com/ 。Mac では，ターミナルで `git` と入力すると，インストールするか聞かれます）。
2. ターミナル（Windows ではコマンドプロンプト）で，教材を置きたいフォルダに移動して，次を実行します。python というフォルダができ，その中に教材がコピーされます。

  git clone https://github.com/HidekiTsuiki/python.git

3. 教材の更新を取り込むには，python フォルダの中で次を実行します。授業の始まる前に行ってください。

  git pull

教材のファイルを直接書き換えていると，git pull でエラーが出ることがあります。演習は，1Tsuiki.ipynb のように，教材を自分の名前のファイルにコピーしてから行ってください（第1回で説明します）。エラーが出た時は，次のコマンドで教材のファイルを元に戻してから，もう一度 git pull してください（自分で書き換えた内容は消えます）。

  git reset --hard

git を使わない場合は，このページの緑色の「Code」ボタンから「Download ZIP」を選んでダウンロードすることもできます。

VS Code で python フォルダを開き（「ファイル」→「フォルダーを開く」），1Jupyter.ipynb を開いて始めてください。
